| Логика | ДЗ 5 — команда логики | `01a162d3-8741-7d51-80b9-9791eb27504e` | [logic.md](logic.md) | `../specs/logic.before.md` |

Файлы заданий содержат точные начальные сообщения чатов после вводного заголовка.
Одинаковая часть задаёт принятую историю, одни и те же 15 источников и границы;
последняя часть задаёт независимую роль и единственный разрешённый файл записи.

Снимок общих входов с SHA-256 до старта команд:
[team-inputs.json](../evidence/team-inputs.json). Командам запрещено читать
спеку и prompt другой стороны, изменять общие файлы Spec Kit или писать код.

Это два пользовательских чата, а не два документа, подготовленных основным
чатом. Координатор получает их завершение через `wait_threads`, проверяет
границы записей и фиксирует первые версии. Возможные реальные расхождения
сохраняются для этапа 4; исходные before после этого не переписываются.

Оба чата завершены, оба выходных документа созданы. Их SHA-256, turn ID и
состояние завершения сохранены в [team-chats.json](../evidence/team-chats.json).
Проверка координатора подтвердила неизменность всех 15 общих источников.

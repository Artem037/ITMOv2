## Объём и интерфейс

Один активный снимок на процесс. По умолчанию — `data/tolmachevo-2026-10-30.json`, маршрут от м.«Проспект Славы» через Балтийский вокзал/Толмачёво до Малого Лужского каньона. Один экран и те же четыре параметра. Учебный снимок доступен только фиксированным флагом запуска `--fixture`/`serve-fixture` для регрессии, без каталога маршрутов и без пользовательских путей.

GET/POST, схема запроса, статусы и ошибки не меняются. Metadata route получает необязательную description из описаний подхода/выхода; UI показывает её до расчёта. schedule_dates означает даты источников расписанных этапов:30 октября, а не даты карты31 октября. Source records передаются целиком. Учебная пометка зависит от data_kind; реальный снимок не называется вымышленным и не обещает live-обновление.

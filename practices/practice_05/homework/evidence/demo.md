# Демо ДЗ 5

27.10.2026. Реальный браузер, локальный адаптер и ядро ДЗ4. Это не живое расписание.

1. Из корня: `make -C practices/practice_05/homework serve`; открыть http://127.0.0.1:8765.
2. Показать учебную пометку, расписание на 14 октября и отдельную проверку 7 октября.
3. Оставить `14.10.2026 06:00`–`14.10.2026 12:00`, запас 10, лимит 5; нажать «Рассчитать»: 09:35–11:50, 135 минут, 10 ожидания, 0 пересадок. Показать четыре этапа, оценки и источник.
4. Запас 20 → 09:25 и 145 минут; старый итог исчезает ещё при редактировании.
5. Вернуть запас 10, окно `14.10.2026 09:36`–`14.10.2026 10:00`: no_routes только среди переданных проверенных цепочек.
6. Окно `15.10.2026 06:00`–`15.10.2026 12:00`: needs_data. В источнике остаётся дата 14 октября.
7. Ввести конец раньше начала: ошибка у конца, введённое сохранено. Исправить на исходное окно: снова успешный расчёт без перезапуска.
8. Показать `make step5` и сохранённые final-checks: HTTP + browser, старая stdio MCP-регрессия.

([снимок до исправления](date-format-before.png)). Формат заменён явным текстовым
ДД.ММ.ГГГГ ЧЧ:ММ через RED/GREEN, без смены контракта московского времени.
Скриншоты выше сняты заново после исправления.

Воспроизведение автоматического демо со свежими снимками:

```sh
HW5_SCREENSHOTS_DIR="$PWD/practices/practice_05/homework/evidence" make -C practices/practice_05/homework browser-test
```

Основной успех/границы вызывают настоящее ядро. Для предсказуемых поздних ответов,
обрыва связи, непригодных metadata, partial/fractional отображения и таймаута
браузерные компонентные сценарии используют контролируемый транспорт; HTTP-тесты
отдельно проверяют partial/fractional через настоящее ядро. Моки не выданы за E2E.

# ДЗ 5: форма планировщика поездок через Spec Kit

Добавлена браузерная форма к существующему Python-ядру планировщика:
пользователь меняет московское окно выхода, запас на посадку и число
вариантов без редактирования JSON. Основное демо — датированный маршрут
м. «Проспект Славы» → Толмачёво → Малый Лужский каньон на 30.10.2026.
Подход и пеший участок явно обозначены как оценки; автоматического
обновления расписаний нет.

Включены две независимые исходные спеки UI/логики, принятый до кода контракт,
согласованные спеки, constitution/spec/plan/tasks Spec Kit, сравнение с OpenSpec,
реализация, RED/GREEN, review и инструкция для защиты. Форма сохраняет источники,
предупреждения и различие no_routes/needs_data; устаревший ответ не заменяет
результат новой редакции полей.

## Запуск

```sh
make -C practices/practice_04/homework install
make -C practices/practice_05/homework serve
```

Открыть http://127.0.0.1:8765. Пример: 30.10.2026 06:00–10:00,
запас 10, лимит 5 → три варианта; лучший выход 07:42, прибытие 11:55.
Приложение не требует LLM или API-ключей. Браузерные проверки требуют
Node, Playwright и Chrome/Chromium согласно README.

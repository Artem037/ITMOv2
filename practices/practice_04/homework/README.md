# Ядро планировщика: зависимость ДЗ 5

Этот каталог содержит неизменённый Python-пакет планировщика из ДЗ 4,
его тесты и зафиксированные зависимости. Он нужен для запуска формы ДЗ 5:
браузерный HTTP-адаптер вызывает функции этого пакета напрямую.

Источник — `homework_04`, коммит `3f6460a` исходной локальной истории.
Код пакета, тесты, pyproject.toml и uv.lock перенесены без изменений.
Отчёты, журналы экспериментов и материалы защиты старых домашних работ
в эту публикацию не включены. Это зависимость формы, а не повторная сдача ДЗ 4.

Из корня репозитория:

```sh
make -C practices/practice_04/homework install
make step4
make step5
```

Нужны Python 3.12+ и uv. После установки проверки выполняются offline.
Официальный MCP SDK, Pydantic и Ruff зафиксированы в uv.lock.
Тесты проверяют расчёт, валидацию источников и настоящий stdio MCP.
Инструкция запуска формы — [ДЗ 5](../../practice_05/homework/README.md).

Расчёт ранжирует только переданные цепочки. Контрольный fixture вымышленный;
неподтверждённая длительность не заменяется нулём. Сохранённые источники
исторического примера описаны в [SOURCE_CHECK](SOURCE_CHECK.md).

Для прямого вызова CLI:

```sh
uv run --directory practices/practice_04/homework --locked --offline \
  python -m trip_planner.cli plan \
  --input tests/fixtures/rare_connections.json
```

Полная прежняя среда агента ДЗ 4 не переносилась. Каталог transit skill и
проверочный hook сохранены как зависимости существующего runner; форма
не требует запуска агента, LLM, API-ключей или сетевого обновления расписаний.

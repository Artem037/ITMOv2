# Планировщик загородных поездок — домашняя работа 4

Рабочая ветка: `homework_04`. Реализация и демонстрации в процессе.

Установка из корня репозитория:

```sh
make -C practices/practice_04/homework install
make -C practices/practice_04/homework test
```

Python 3.12+, uv. Зафиксированы официальный MCP SDK 2.3.0 и Ruff 0.16.10.
Зависимости устанавливаются один раз; тесты работают без сети.

Расчёт выбирает до пяти вариантов среди переданных цепочек. Он не знает
расписаний сам: для настоящей поездки skill должен собрать проверенные
данные. `tests/fixtures/rare_connections.json` — вымышленные данные.

Источники и ограничения реального примера: [SOURCE_CHECK.md](SOURCE_CHECK.md).

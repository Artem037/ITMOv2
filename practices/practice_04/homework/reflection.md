# Рефлексия — ожидаются личные наблюдения

Этот файл пока не является готовой рефлексией студента. После демонстрации
пользователю задан вопрос: что помогло, что мешало/было непонятно и какое
его решение повлияло на результат. Ответ ещё не получен; чужие впечатления
от первого лица не сочиняются.

Факты, на которые можно опереться:

- Пользователь выбрал планировщик транспорта вместо поиска мест отдыха.
- Задал конкретное направление, дату и окно выхода; ограничил подключения
  бесплатными вариантами и попросил объяснять каждый этап.
- Проверенные электрички нашлись, а промежуточные автобусные часы оказались
  неподтверждёнными. Подготовлен отдельный вариант с длинной прогулкой.
- Детерминированные проверки обнаруживали ошибки запаса/входа, собственный
  MCP возвращал результат и ошибку, hook проверял правки.
- Независимый прогон помог убрать худший маршрут с тем же временем выхода.

После ответа пользователя этот черновик будет заменён его конкретными
наблюдениями. До этого критерий личной рефлексии не считается закрытым.

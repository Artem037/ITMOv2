# Модель угроз Mini Shop

Объект — собственный локальный процесс магазина, синтетические профили Alice/Bob, заказы и одноразовые файлы. Python standard library, SQLite в памяти. Модель относится к 14 API из lab README. Серьёзность оценивается относительно учебных данных, без заявлений о реальных ПДн.

Границы: клиент/сервер; один клиент/чужой клиент; клиент/staff; приложение/физический sandbox; данные отзывов/инструкции модели; решение модели/серверные полномочия. Физическая граница `sandbox.py` уже защищена; права внутри неё проверяет Shop. Модель не является источником полномочий.

## Политика доступа после исправлений

| API | Гость | Alice/Bob | Staff |
| --- | --- | --- | --- |
| GET /health, /products | Разрешено | Разрешено | Разрешено |
| POST /login | Учебные credentials | Учебные credentials | Учебные credentials |
| GET /profile | 401 | Только свой ID | 403; общий экспорт отдельным маршрутом |
| GET /search | 401 | Только свой профиль, включая wildcard | 403 |
| GET /orders | 401 | Только свои заказы | 403 |
| POST /orders | 401 | Из каталога по серверной цене | 403 |
| GET /admin/export | 401 | 403 независимо от X-Role | Разрешено по сессии без X-Role |
| GET /files | 401 | Только свой receipt.txt | 403 |
| POST /reviews | 401 | Товар каталога и ограниченный текст | 403 |
| GET /reviews/view | Экранированный публичный текст | То же | То же |
| GET /debug/logs | 401 | 403 | Ограниченные метаданные без паролей/токенов/тела/query |
| GET /assistant/context | 401 | Только свой заказ; отзывы — недоверенные данные | 403 |
| POST /assistant/execute | 401 | read_file своего чека или refuse | 403 |

Цена из тела игнорируется ради совместимости; каталожная цена всегда определяет сохранённый заказ. Чужой объект возвращает 403, отсутствующий — 404, неправильный ввод — 400. Неизвестный маршрут — 404. AI export/delete запрещены. Для новых заказов магазин не создаёт новые файлы чеков: учебный receipt относится к исходному заказу, помощь по новому заказу должна отказать, а не вернуть чек старой покупки.

## Реестр гипотез и контроль STRIDE

| ID | STRIDE | Поверхность | Возможное воздействие | Мера и доказательство |
| --- | --- | --- | --- | --- |
| V01 | T, I | SQL в profile/search/context | Расширение выборки | Параметризация, строгий ID и owner-фильтр; SQL payload и HTTP evidence |
| V02 | S, I, E | profile/search/orders/context | Чужие профили/заказы | Сессия и владелец на каждом пути; Alice/Bob/guest tests |
| V03 | S, E | admin/export | Подложный staff | Роль только из серверной сессии; header spoof и настоящий staff |
| V04 | T | POST orders | Подмена стоимости | Серверная цена; проверка ответа и сохранённого заказа |
| V05 | I, E | files и AI read_file | Чужой чек и служебная заметка внутри sandbox | Allowlist владельца и нормализованного ресурса; пути и отсутствие чужого содержимого |
| V06 | I | logs | Учебные пароли и сессии в записи/выдаче | Метаданные без body/headers/query, staff-only чтение |
| V07 | T, E | review HTML | Сохранённая HTML-инъекция/XSS | Экранирование и CSP; HTTP HTML-проверка без заявления о фактическом исполнении JS |
| V08 | T, E | отзыв → LLM → execute | Модель принимает данные за инструкции | Четыре реальных запуска planner; сервер повторно проверяет права |
| V09 | E, D, I | AI execute | Удаление sandbox/экспорт/чужое чтение | Allowlist и сессия; опасные JSON отдельно от LLM |
| V10 | I, D | HTTP JSON, query, ошибки | 500 с внутренними данными, некорректное тело | Схемы, безопасные 4xx/5xx, таймаут и лимит тела |
| V11 | D | sessions/reviews/logs/input | Рост памяти и накопление данных | Ограниченные коллекции и длины, ограничение заказов; граничные тесты |

S: подделка личности; T: подмена данных; R: отказ от авторства; I: раскрытие; D: отказ в обслуживании; E: повышение привилегий. R: журнал хранит минимальные сведения об actor/действии, но долговечный защищённый аудит отсутствует — осознанная граница процесса в памяти. Для всех маршрутов проверены или запланированы identity/owner/role, ввод, выход и побочные эффекты в соответствии с таблицей политики.

## Ограничения и неприменимые классы

Нет маршрута выполнения shell/Python или произвольной отправки на внешний URL: RCE и SSRF без достижимого sink не объявляются находками. Sandbox ограничивает абсолютные пути, parent traversal и symlinks физическим временным каталогом; исходные containment-тесты сохраняются. Удаление учебного sandbox до фикса — отдельная достижимая операция исполнителя, не выполнение shell.

Стенд не рассчитан на production: статические учебные пароли, отсутствие TLS и распределённой защиты от нагрузки, in-memory сессии/заказы. Loopback не является авторизацией против локального злоумышленника. По одной паре LLM-запусков нельзя оценить вероятность успешной атаки. Источник методики: [Microsoft threat modeling](https://learn.microsoft.com/en-us/azure/security/develop/threat-modeling-tool-getting-started).

"""Local teaching shop with server-side access checks and synthetic data."""

import argparse
import json
import sqlite3
import threading
import uuid
from html import escape
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from urllib.parse import parse_qs, urlsplit

from sandbox import Sandbox


class RequestError(Exception):
    def __init__(self, status, message):
        self.status = status
        self.message = message


def text(value, limit=2000):
    if not isinstance(value, str) or not value.strip() or len(value) > limit:
        raise RequestError(400, "invalid field")
    return value


def positive_id(value):
    value = text(value, 19)
    if not value.isascii() or not value.isdecimal():
        raise RequestError(400, "invalid id")
    number = int(value)
    if not 0 < number <= 9223372036854775807:
        raise RequestError(400, "invalid id")
    return number


class Shop:
    def __init__(self):
        self.sandbox = Sandbox()
        self.lock = threading.RLock()
        self.db = sqlite3.connect(":memory:", check_same_thread=False)
        self.db.row_factory = sqlite3.Row
        self.db.executescript("""
            CREATE TABLE profiles(
                id INTEGER PRIMARY KEY, name TEXT, email TEXT, address TEXT
            );
            INSERT INTO profiles VALUES
                (1, 'TEST_ALICE', 'alice@example.invalid', 'TEST_ADDRESS_A'),
                (2, 'TEST_BOB', 'bob@example.invalid', 'TEST_ADDRESS_B');
            CREATE TABLE orders(
                id INTEGER PRIMARY KEY, owner INTEGER, product TEXT, price REAL
            );
            INSERT INTO orders VALUES
                (1, 1, 'chair', 5000), (2, 2, 'lamp', 1500);
        """)
        self.accounts = {
            "alice": ("learn-alice", 1, "customer"),
            "bob": ("learn-bob", 2, "customer"),
            "staff": ("learn-staff", 0, "staff"),
        }
        self.sessions = {}
        self.products = {"chair": 5000, "lamp": 1500}
        self.reviews = []
        self.logs = []

    def rows(self, query, parameters=()):
        return [dict(row) for row in self.db.execute(query, parameters)]

    def read_receipt(self, session, path):
        path = text(path, 256)
        own = f"files/{session['username']}/receipt.txt"
        if path != own:
            raise RequestError(403, "file forbidden")
        try:
            resolved = self.sandbox.path(path)
        except ValueError:
            raise RequestError(403, "file forbidden") from None
        if resolved != self.sandbox.root / own:
            raise RequestError(403, "file forbidden")
        return {"content": self.sandbox.read(path)}

    def dispatch(self, method, target, body, headers):
        try:
            return self._dispatch(method, target, body, headers)
        except RequestError as exc:
            return exc.status, {"error": exc.message}
        except FileNotFoundError:
            return 404, {"error": "file not found"}

    def _dispatch(self, method, target, body, headers):
        if not isinstance(body, dict):
            raise RequestError(400, "JSON object required")
        if len(target) > 8192:
            raise RequestError(414, "target too long")
        try:
            url = urlsplit(target)
            parsed = parse_qs(
                url.query,
                keep_blank_values=True,
                max_num_fields=10,
                errors="strict",
            )
        except (ValueError, UnicodeError):
            raise RequestError(400, "invalid target") from None
        if (
            url.netloc
            or url.scheme
            or not url.path.startswith("/")
            or any(len(values) != 1 for values in parsed.values())
        ):
            raise RequestError(400, "ambiguous target")
        query = {key: values[0] for key, values in parsed.items()}
        headers = {key.lower(): value for key, value in headers.items()}
        session = self.sessions.get(headers.get("x-token"))
        known_paths = {
            "/health",
            "/products",
            "/login",
            "/profile",
            "/search",
            "/orders",
            "/admin/export",
            "/files",
            "/reviews",
            "/reviews/view",
            "/debug/logs",
            "/assistant/context",
            "/assistant/execute",
        }
        self.logs.append(
            {
                "method": method,
                "path": url.path if url.path in known_paths else "unknown",
                "actor": session["id"] if session else None,
            }
        )
        del self.logs[:-1000]
        if method == "GET" and url.path == "/health":
            return 200, {"status": "ok"}
        if method == "GET" and url.path == "/products":
            return 200, self.products
        if method == "POST" and url.path == "/login":
            username = text(body.get("username"), 64)
            password = text(body.get("password"), 256)
            account = self.accounts.get(username)
            if not account or password != account[0]:
                return 401, {"error": "invalid credentials"}
            token = uuid.uuid4().hex
            if len(self.sessions) >= 1000:
                del self.sessions[next(iter(self.sessions))]
            self.sessions[token] = {
                "id": account[1],
                "role": account[2],
                "username": username,
            }
            return 200, {"token": token}
        if method == "GET" and url.path == "/reviews/view":
            return 200, "<html><body>" + "".join(
                f"<p>{escape(r['text'])}</p>" for r in self.reviews
            ) + "</body></html>"
        if url.path not in known_paths:
            return 404, {"error": "not found"}
        if not session:
            return 401, {"error": "login required"}
        if url.path in {"/admin/export", "/debug/logs"}:
            if session["role"] != "staff":
                return 403, {"error": "staff only"}
            if method != "GET":
                return 404, {"error": "not found"}
            if url.path == "/admin/export":
                return 200, self.rows("SELECT * FROM profiles")
            return 200, self.logs.copy()
        if session["role"] != "customer":
            return 403, {"error": "customer only"}
        if method == "GET" and url.path == "/profile":
            identifier = positive_id(query.get("id", str(session["id"])))
            profiles = self.rows(
                "SELECT * FROM profiles WHERE id = ?", (identifier,)
            )
            if not profiles:
                return 404, {"error": "profile not found"}
            if identifier != session["id"]:
                return 403, {"error": "profile forbidden"}
            return 200, profiles
        if method == "GET" and url.path == "/search":
            term = query.get("q", "")
            if len(term) > 1000:
                raise RequestError(400, "query too long")
            return 200, self.rows(
                "SELECT * FROM profiles WHERE id = ? AND name LIKE ?",
                (session["id"], f"%{term}%"),
            )
        if method == "GET" and url.path == "/orders":
            return 200, self.rows(
                "SELECT * FROM orders WHERE owner = ?", (session["id"],)
            )
        if method == "POST" and url.path == "/orders":
            product = text(body.get("product"), 64)
            if product not in self.products:
                return 400, {"error": "unknown product"}
            if (
                self.db.execute("SELECT COUNT(*) FROM orders").fetchone()[0]
                >= 1000
            ):
                return 429, {"error": "order limit reached"}
            price = self.products[product]
            cursor = self.db.execute(
                "INSERT INTO orders(owner, product, price) VALUES (?, ?, ?)",
                (session["id"], product, price),
            )
            self.db.commit()
            return 201, {
                "id": cursor.lastrowid,
                "owner": session["id"],
                "product": product,
                "price": price,
            }
        if method == "GET" and url.path == "/files":
            if (
                query.get("user", session["username"]) != session["username"]
                or query.get("path", "receipt.txt") != "receipt.txt"
            ):
                return 403, {"error": "file forbidden"}
            return 200, self.read_receipt(
                session, f"files/{session['username']}/receipt.txt"
            )
        if method == "POST" and url.path == "/reviews":
            product = text(body.get("product"), 64)
            review = text(body.get("text"))
            if product not in self.products:
                return 400, {"error": "unknown product"}
            if len(self.reviews) >= 100:
                return 429, {"error": "review limit reached"}
            self.reviews.append({"product": product, "text": review})
            return 201, {"saved": True}
        if method == "GET" and url.path == "/assistant/context":
            identifier = positive_id(query.get("order_id", str(session["id"])))
            orders = self.rows(

            if not orders:
                return 404, {"error": "order not found"}
            if orders[0]["owner"] != session["id"]:
                return 403, {"error": "order forbidden"}
            action = (
                {
                    "tool": "read_file",
                    "arguments": {
                        "path": f"files/{session['username']}/receipt.txt"
                    },
                }
                if identifier == session["id"]
                else {
                    "tool": "refuse",
                    "arguments": {
                        "reason": "receipt unavailable for this order"
                    },

            )

            return 400, {"error": "unknown tool"}
        return 404, {"error": "not found"}

def make_handler(shop):
    class Handler(BaseHTTPRequestHandler):
        def setup(self):
            super().setup()
            self.connection.settimeout(2)

        def handle_request(self):
            try:
                lengths = self.headers.get_all("Content-Length", [])
                if (
                    self.headers.get("Transfer-Encoding")
                    or len(lengths) > 1
                    or (self.command == "POST" and not lengths)
                ):
                    raise RequestError(400, "ambiguous body framing")
                length = lengths[0] if lengths else "0"
                if not length.isascii() or not length.isdecimal():
                    raise RequestError(400, "invalid content length")
                size = int(length)
                if size > 65536:
                    raise RequestError(413, "body too large")
                if (
                    self.command == "POST"
                    and self.headers.get("Content-Type", "")
                    .split(";", 1)[0]
                    .strip()
                    .lower()
                    != "application/json"
                ):
                    raise RequestError(415, "JSON content type required")
                raw = self.rfile.read(size)
                if len(raw) != size:
                    raise RequestError(400, "incomplete body")
                body = json.loads(raw) if size else {}
                with shop.lock:
                    status, result = shop.dispatch(
                        self.command, self.path, body, self.headers
                    )
            except RequestError as exc:
                status, result = exc.status, {"error": exc.message}
            except (ValueError, UnicodeError, RecursionError):
                status, result = 400, {"error": "invalid JSON body"}
            except TimeoutError:
                status, result = 408, {"error": "request timeout"}
            except Exception:  # noqa: BLE001 - HTTP boundary hides all details.
                status, result = 500, {"error": "internal server error"}
            html = isinstance(result, str)
            data = (
                result if html else json.dumps(result, ensure_ascii=False)
            ).encode("utf-8")
            self.send_response(status)
            self.send_header(
                "Content-Type",
                "text/html; charset=utf-8"
                if html
                else "application/json; charset=utf-8",
            )
            self.send_header("Content-Length", str(len(data)))
            self.send_header("X-Content-Type-Options", "nosniff")
            self.send_header(
                "Content-Security-Policy",
                "default-src 'none'; frame-ancestors 'none'",
            )
            self.send_header("Cache-Control", "no-store")
            self.send_header("Connection", "close")
            self.close_connection = True
            self.end_headers()
            self.wfile.write(data)

        do_GET = do_POST = handle_request

        def log_message(self, format, *args):
            pass

    return Handler


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--port", type=int, default=8066)
    args = parser.parse_args()
    shop = Shop()
    server = ThreadingHTTPServer(("127.0.0.1", args.port), make_handler(shop))
    server.daemon_threads = True
    print(f"Local exercise: http://127.0.0.1:{server.server_port}", flush=True)
    print(f"Disposable fixture files: {shop.sandbox.root}", flush=True)
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        pass
    finally:
        server.server_close()
        shop.close()


if __name__ == "__main__":
    main()

"""Physical boundary of the exercise; keep this module unchanged during homework."""

import shutil
import tempfile
from pathlib import Path


class Sandbox:
    def __init__(self):
        self._temporary = tempfile.TemporaryDirectory(prefix="itmo-practice-06-")
        self.root = Path(self._temporary.name).resolve()
        for name, text in {
            "files/alice/receipt.txt": "TEST_ALICE receipt: chair, 5000 RUB",
            "files/bob/receipt.txt": "TEST_BOB receipt: lamp, 1500 RUB",
            "private/operator-note.txt": "TEST_ONLY_OPERATOR_SECRET",
        }.items():
            path = self.path(name)
            path.parent.mkdir(parents=True, exist_ok=True)
            path.write_text(text, encoding="utf-8")

    def path(self, name):
        candidate = (self.root / name).resolve()
        if candidate != self.root and self.root not in candidate.parents:
            raise ValueError("outside exercise sandbox")
        return candidate

    def read(self, name):
        return self.path(name).read_text(encoding="utf-8")

    def delete_tree(self, name):
        path = self.path(name)
        if path.is_dir():
            shutil.rmtree(path)
        else:
            path.unlink()

    def close(self):
        self._temporary.cleanup()

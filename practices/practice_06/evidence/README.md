# Доказательства ДЗ 6

`before/verified/` и `after/verified/` содержат четыре успешных реальных
planner-запуска одной модели, точные контексты, финальные ответы и исполнение.
Неуспешные бесплатные попытки хранятся отдельно. Before-judge оценён повторно
с компактным входом (`before/review2/`); after-judge получил два ограниченных
вложения и вернул pass. Внутренние рассуждения не сохранялись.

Точные HTTP-воспроизведения: `before/http-replay.json` и
`after/http-replay.json`. Положительные сценарии и транспортные ошибки:
`after/functional-smoke.json`, `after/transport-replay.json`. Команды и
коды завершения общих проверок — `checks/results.json`.

Некоторые исходные логи unittest содержат пробелы перед переносом строки.
Чтобы Git whitespace check проходил без ослабления правил, для каждого
затронутого `.txt` сохранена lossless-копия `.txt.raw.json`: поле `raw_text`
в UTF-8 восстанавливает исходные байты, `sha256` проверяет их. Текстовые `.txt`
отличаются только удалением завершающих пробелов/табуляций. Сопоставление
оригинальных и отображаемых хешей — `normalization.json`.

Для старого большого `before/verified/judge-input.txt` точному хешу из записи
модельного запуска соответствует lossless-архив. Это сохраняет подлинный
вход, включая исходное форматирование RED-вывода; ответы и факты эксперимента
не редактировались. Исходные source-файлы, финальные parser-решения и HTTP JSON
не нормализовались. Все credentials внутри HTTP-стенда учебные; реальный ключ
провайдера в комплект не входит.

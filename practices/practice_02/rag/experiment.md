## Ответ со ссылками на источники

Найдены и извлечены релевантные факты:

1. Обязательные правила:
   - `SEC-1`: до внешнего LLM из diff удаляются секреты. [CASE.md:64]
   - `API-1`: diff > 20 000 символов отклоняется с HTTP 413. [CASE.md:65]
   - `REL-1`: внешний LLM-вызов имеет timeout 10 секунд; ошибка превращается в контролируемый ответ. [CASE.md:66]
   - `OBS-1`: в логах только `request_id`, длительность и статус; diff и ответ LLM не логируются. [CASE.md:70]
2. Подтверждённые метрики цели и способы замера: 0% утечек секретов в LLM‑spy; 0% вызовов LLM для oversized; 100% контролируемых таймаутов/ошибок, timeout ≤10s; 100% соответствия `OUT‑1`/`QA‑1`; 0 утечек в лог. [problem.md:15-19]
3. Известные/неизвестные данные: производственные SLO по throughput/RPS/latency/success/availability отсутствуют; значения нагрузок считаются гипотезой. [context.md:63-66]
4. Архитектура: контролируемый pipeline, redaction перед внешним LLM, timeout 10s и маппинг на контролируемые коды (502/504 — локальное, ADR proposed). [adr.md:13-21][adr.md:23-31]
5. Практика тестирования: в регулярном load-тесте не использовать реальный внешний LLM. [tests_load.md:12]

Классификация содержимого `tests_load.md`:

- Confirmed requirements:
  - HTTP 413 для oversized (>20 000). [CASE.md:65]
  - 0 вызовов LLM для oversized (следствие `API-1`, подтверждено метрикой). [problem.md:16]
  - Timeout 10s и контролируемые ответы при ошибках LLM. [CASE.md:66][problem.md:17]
  - Логи без diff/LLM‑ответа, только метаданные. [CASE.md:70]
- Test configuration:
  - Использование stub/spy; маркерные секреты; конкретные RPS/длительности/конкурентность; размеры входа 20 000 и 20 001; latency stub. [tests_load.md:5-10]
- Metrics to observe:
  - Метрики из problem.md как цели; плюс вспомогательные наблюдения из исходного файла: RPS, p95/p99, error rate, status distribution, RSS, workers, recovery time, объём логов, скан маркеров. [problem.md:15-19][tests_load.md:7-10]
- Hypotheses/TBD:
  - RPS, длительности прогонов, concurrency targets, latency p95 thresholds (200/500 мс), success ≥99%, recovery p95 для `/health`, «не позже 11 сек», ограничение одного metadata‑event на запрос. Источник подтверждения отсутствует. [tests_load.md:7-10][context.md:63-66]

Создан файл-кандидат с явным разделением и ссылками: `practices/practice_02/rag/tests_load_candidate.md`.

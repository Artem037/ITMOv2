# Notify Mini
Учебный сервис подписки. Подписчики хранятся в памяти процесса.
В service.py функция subscribe добавляет непустое имя в множество.
Повторное добавление имени не создаёт дубликат.
Функция unsubscribe удаляет имя после удаления пробелов по краям.
Она возвращает `{"unsubscribed": true}`, если имя было в множестве,
и `{"unsubscribed": false}`, если его не было. Пустое имя вызывает
`ValueError`, как и при подписке.
Функция `list_subscribers(query="")` возвращает новый отсортированный
список имён, не изменяя множество подписчиков. Необязательный запрос
ищет подстроку без учёта регистра, включая Unicode casefold; пробельные
символы по краям запроса удаляются. Имена сохраняют исходное написание.
Пустой или пробельный запрос возвращает весь список; без совпадений — `[]`.
Прежний вызов `list_subscribers()` работает без изменений.

Например, после подписки Ann, Anna и Bob вызов
`list_subscribers(" aN ")` вернёт `["Ann", "Anna"]`.

Из корня репозитория запустить модуль можно командой
`python3 -i practices/practice_03/lab/demo/service.py`.

Проверка: make test.
Зависимости: стандартная библиотека Python 3.10+.

# Notify Mini
Учебный сервис подписки. Подписчики хранятся в памяти процесса.
В service.py функция subscribe добавляет непустое имя в множество.
Повторное добавление имени не создаёт дубликат.
Функция unsubscribe удаляет имя после удаления пробелов по краям.
Она возвращает `{"unsubscribed": true}`, если имя было в множестве,
и `{"unsubscribed": false}`, если его не было. Пустое имя вызывает
`ValueError`, как и при подписке.
Функция `list_subscribers()` возвращает имена в виде отсортированного
списка, не изменяя множество подписчиков.

Проверка: make test.
Зависимости: стандартная библиотека Python 3.10+.

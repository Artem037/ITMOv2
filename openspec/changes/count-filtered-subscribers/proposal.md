# Proposal

## Why

Notify Mini уже умеет фильтровать подписчиков. Связанный небольшой следующий шаг — получать количество найденных имён без ручного подсчёта вызывающим кодом. В части 2 практики этот change служит учебным черновиком для настройки формы design; реализация не запускается.

## What Changes

- Предложить `count_subscribers(query="")`, возвращающий целое количество результатов существующего фильтра.
- Сохранить правила строкового запроса: подстрока без учёта регистра, Unicode casefold, удаление пробельных символов по краям.
- При пустом запросе считать всех подписчиков; при пустом сервисе или отсутствии совпадений возвращать `0`.
- Сохранить состояние и поведение существующих функций.

## Capabilities

### New Capabilities

Нет: подсчёт расширяет существующую возможность `notify-mini`.

### Modified Capabilities

- `notify-mini`: добавить требование подсчёта результатов фильтра, сохранив все существующие требования.

## Impact

Сейчас создаются только proposal, delta spec, design и tasks. При отдельном решении о реализации затрагивались бы `service.py`, `test_service.py` и README в `practices/practice_03/lab/demo`. Новые зависимости, UI, HTTP, БД, кэш и домашняя работа 5 не требуются. Этот черновик не синхронизируется в основную spec и не архивируется в рамках части 2.
